# Automated Subspace Relay

## Overview
A deterministic protocol for routing subspace communication signals based on signal strength and integrity metrics.

## Features
- **Rule-based Routing:** Categorizes packets as optimal, degraded, or lost.
- **Automated Processing:** Iterates over signal queues to determine relay status.
- **UI Dashboard:** Visualizes packet health.

## Technologies
- HTML5 / CSS3 (Modern UX)
- Vanilla JavaScript
- Node.js (for testing)
