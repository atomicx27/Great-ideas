# Agentic Dark Matter Tuner

## Overview
A single-agent AI system that dynamically optimizes dark matter containment fields based on real-time sensory data and instability metrics.

## Features
- **Agentic AI:** Uses an LLM to determine the optimal tuning parameters.
- **Dynamic Adjustments:** Adjusts field harmonics to maximize stability.
- **Live Logging:** Transparent view of agent thought processes and actions.

## Technologies Used
- HTML5 / CSS3 (Modern UX)
- Vanilla JavaScript
- Shared LLM API (`shared/llm-api.js`)
- Node.js (for testing)

## Testing
Run \`node --test\` from the directory to execute tests.
