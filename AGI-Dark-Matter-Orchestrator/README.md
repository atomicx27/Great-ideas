# AGI Dark Matter Orchestrator

## Overview
A multi-agent swarm orchestrator that coordinates specialized AI agents to monitor, analyze, and tune dark matter containment fields across wide sector areas simultaneously.

## Features
- **Multi-Agent Swarm:** Orchestrator controls Agents Alpha, Beta, and Gamma.
- **Provider Switching:** Integrates with OpenAI, Anthropic, or Ollama via `shared/llm-api.js`.
- **Parallel Processing:** Agents execute simulated containment tuning concurrently.

## Technologies Used
- HTML5 / CSS3 (Modern UX)
- Vanilla JavaScript
- `fetchOpenAI`, `fetchAnthropic`, `fetchOllama`

## Testing
Run \`node --test\` to execute unit tests.
