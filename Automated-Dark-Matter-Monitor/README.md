# Automated Dark Matter Monitor

## Overview
A deterministic, rule-based system for monitoring ambient dark matter density levels across local space-time regions.

## Features
- **Deterministic Scanning:** Automates the detection of dark matter signatures.
- **Classification Rules:** Categorizes density as Low, Medium, or High.
- **Status Dashboard:** Real-time feedback and visualization.

## Technologies Used
- HTML5 / CSS3 (Modern UX)
- Vanilla JavaScript
- Node.js (for unit testing)
